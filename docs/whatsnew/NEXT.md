# What's new since 1.0.6

Hand-written notes for the next release. The release workflow uses the bullets
below as the "Changes" section of the GitHub release and the post-update page
(`docs/whatsnew/<version>/`) — but only while the heading's "since" version is
the previous tag, so a stale file after a release is ignored and the commit
list is used instead. Rewrite the heading and the bullets for each release.

- **Compact mode for vertical tabs** (Ctrl/Cmd+Alt+C): the page gets the whole window; the toolbar, address bar, tabs and player live in one column at the edge that slides out when you touch it and hides again when you leave — the address bar goes with it. Drag the column's edge to resize it.
- **Now Playing, rebuilt**: a bigger toolbar pill and a real player — title and artist (long ones scroll), a seekable bar with real times (no more "live"), previous / play / next, mute, and a volume slider that moves the page's own volume (YouTube Music's slider follows it, and its changes show up here). Pixel-art icons. No flicker.
- **Calendar**: several Google calendars on one board with roles (Mine / Theirs / Shared), a Notion-style item editor, Google-Calendar-style details, one-click delete, an expandable full-window board, and a plain reason when connecting fails.
- **Themes**: renamed; light palettes make the browser and web pages light; Night Sky is dark pastel lavender and the tab strip follows it; the orb has a speed setting; the moon is centred.
- **Rishi**: one at a time; the admin panel switches him to Tea; his mood syncs between the two browsers.
- **Gone**: the Discord / Apple Music / Instagram side panels and the feature-request button.
- **Fixed**: the sidebar tool strip no longer pops back open after vertical tabs are turned off.
