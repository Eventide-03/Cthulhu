ART SLOT — release hero (16:9)
1.0.1

What's new

Cthulhu updated itself in the background. Here's what changed.

Changes

  • Updates: bake the host into application.ini.in instead of the placeholder
  • CI: read updateHostname with sed, not node (Windows ate the backslashes)
  • Updates: make MOZ_APPUPDATE_HOST real, so a build can actually update itself
  • Home page: theme engine, colour controls, icons, five new widgets
  • Pinned tabs: Ctrl/Cmd+W unloads them instead of doing nothing
  • Home button: put it back at the start of the strip if a profile lost it
  • Home button: make it unhideable, and put pinned tabs on its side of the divider
  • Prefs: define app.update.checkInstallTime.days so the startup check runs
  • macOS: drop CFBundleIconName so our icon is the one the Dock draws
  • Branding: ship a crisp macOS app icon instead of Surfer's blurred one
  • Branding: replace the placeholder logos with the real pixel art
  • Home button: remove Firefox View at the source, replace it with the Home tab
  • Download page: name the release, not the visitor, on an unavailable build
  • CI: use a POSIX temp dir for the Windows MAR signing key
  • CI: find the real Windows installer, and never substitute a test binary
  • CI: stop `set -e` from killing the installer search before it can report
  • CI: drop the redundant `mach build installer` -- packaging already does it
  • CI: turn off Windows debug symbols, and make the pagefile step tell the truth
  • CI: give the Windows build room to finish (memory, not configuration)
  • CI: install MozillaBuild before any mach call on Windows
  • Download page: Gatekeeper note; CI: install Surfer locally on Windows
  • Publish update manifests for v1.0.0
  • **macOS** (universal — Apple Silicon + Intel): `Cthulhu-1.0.1-macos-universal.dmg`
  • **Windows x64**: `Cthulhu-1.0.1-windows-x64.exe`
