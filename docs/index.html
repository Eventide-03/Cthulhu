⚠️ macOS will refuse to open it at first

The Mac build is unsigned and un-notarized, for the same reason as Windows below — Apple's Developer Program is a yearly fee this project doesn't carry, and notarization has no free tier.

Gatekeeper will say Cthulhu "cannot be opened because the developer cannot be verified". Opening it the normal way gives you no choice but Move to Bin, so do this instead, once:

  1. Drag Cthulhu into your Applications folder.
  2. Right-click it (or Control-click) and choose Open.
  3. In the dialog that appears, click Open again.

macOS remembers the exception, so every launch after that is normal. If the dialog still won't let you through, run xattr -d com.apple.quarantine /Applications/Cthulhu.app in Terminal.

This means macOS can't confirm who published the app — not that anything is wrong with it. Verify your download against the SHA256 checksum published with every release if you'd like to be certain.

⚠️ Windows will warn you before it runs

Cthulhu's Windows installer is unsigned. This is deliberate — code-signing certificates are an ongoing cost this project doesn't carry.

Windows SmartScreen will say "Windows protected your PC". To continue, click More info, then Run anyway.

This warning means Windows doesn't recognise the publisher — not that anything is wrong with the file. You can verify your download against the SHA256 checksum published with every release.

Updates are automatic

Cthulhu updates itself in the background, the same way Firefox does. You only need to download from this page once.
